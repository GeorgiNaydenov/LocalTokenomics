# Pricing Screen Screen Map

This view shows the pricing screen: the rate table, the rules that turn an input price into cache prices, and the models that have tokens but no price. It helps a developer see how the app explains cost and what a person must do to fix a missing price. Each numbered highlight matches a row in the table of the screen note.
